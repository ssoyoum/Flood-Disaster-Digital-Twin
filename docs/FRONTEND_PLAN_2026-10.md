├ 왼쪽: 특보 영향 시설 ┬ 가운데: 지도(시설 점, 단계 색) ┬ 오른쪽 드로어 ───────┤
│ 탭: 특보 영향 | 주의 이상 | │                              │ [시설 판단] [채점표] [에이전트] │

### 공식 기준 적용 상태 (시설 판단 탭)

기준은 기관 지침이고 FloodOps는 시설에 대입만 한다. 행마다 «출처·조건 / 상태 / 선행·현재값».

| 행 | 출처 | 상태 값 | 지금 자료 |
| --- | --- | --- | --- |
| 홍수특보 | 홍수통제소 발령 | 홍수주의보 · 홍수경보 · 해당 없음 | 실시간·과거 재생 모두 |
| 하천 수위 | 홍수통제소 관측소 기준수위 | 주의보 수위 초과 · 경보 수위 초과 · 계획홍수위 도달 | 실시간·재생 |
| 호우특보 | 기상청 | 시군구 특보 적용 · 해당 없음 · 미확인 | 실시간만. 과거 이력은 API 승인 대기 |
| 강우 누적 · 호우특보 기준량 | 가까운 강우계 1·3·12시간 | 기준 미만 · 주의보량 · 경보량 | 참고값. 시설 기준 아님 |
| 침수심 (행안부 통제기준) | 행안부 | 자료 없음 | 원문 확인 중 · 센서 비공개 |
| FloodOps 규칙 (비교 후보) | `river_stage_v1` | 정상 · 감시 · 통제 검토 / 미등록 | 운영 시설만 |

## 4. 원칙

- 공식 기준과 FloodOps 규칙을 섞지 않는다. FloodOps 규칙은 항상 «비교 후보»로 점선 표시한다.
- 자료가 없으면 무강우·정상으로 보이지 않게 «미확인 / 자료 없음»으로 드러낸다.
- 권고는 통제를 실행하지 않는다. «담당자 판단·현장 확인이 우선» 문구를 권고 옆에 둔다.
- 운영 등록 전 시설은 담당자 기록을 받지 않는다(등록 관문: 유입 경로·대표 관측소·현장 계측·검증 사건).
- 수치는 API 값을 그대로 쓰고 화면에서 다시 계산하지 않는다(채점표).

## 5. 발전 과제: 실제 지하차도 연결

흐름의 마지막 칸(공식 특보 → 시설 기준 적용 → 통제 검토·담당자 기록 → 사건 채점 → **실제 지하차도 연결**)은 지금 화면에 «발전 과제»로만 표시한다. 공개 API가 없어 기관 협력이 전제다.

| 연결 대상 | 화면에서 바뀌는 곳 |
| --- | --- |
| 진입차단시설 작동 기록 | 시설 판단 탭에 «권고 → 실제 차단» 시각 차이 표시 |
| 지하차도 침수심·배수펌프 계측 | 공식 기준 표의 «침수심» 행이 실제 판정으로 바뀜 |
| 지자체 통제·해제 기록 | 효과성 채점표의 정답이 보도 시각에서 공식 기록으로 바뀜 |
