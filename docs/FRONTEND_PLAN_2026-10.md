├ 왼쪽: 특보 영향 시설 ┬ 가운데: 지도(단계 색 · ② 충족 빨간 테두리) ┬ 오른쪽 드로어 ┤
│ 탭: 특보 영향 | ② 충족 |    │                                    │ [시설 판단] [채점표] [에이전트] │

### 즉시 통제 조건 (시설 판단 탭 · 운영 시설 상세 공통)

국토부 「도로터널 방재·환기시설 설치 및 관리지침」 2.1.7(8)의 조건 번호를 그대로 쓴다. 기준은 기관 지침이고 FloodOps는 시설에 대입만 한다.

| 조건 | 내용 | 판정 | 자료 |
| --- | --- | --- | --- |
| ② | 홍수특보 등으로 범람 우려 통보 | 충족 · 해석상 미충족 · 미충족 | 홍수통제소 발령. «범람 우려 통보»를 홍수경보부터(기본)/주의보부터로 전환. 오송 재생은 06:34 계획홍수위 도달 경고 통보(국조실 경과표)를 함께 표시 |
| ④ | 호우특보 중 급격한 수위 증가 예상 | 담당자 판단 · 미충족 · 판정 보류 | 기상청 실시간 특보 + 수위 상승 속도. 과거 재생은 특보 이력 API 승인 전이라 «판정 보류». «급격» 수치 기준은 지침에 없음 |
| ① ③ ⑤ | 배수펌프 미작동·관계기관 통보·배수용량 초과 | 현장 확인 | 공개 자료 없음 |
| (7) | 침수심 통제기준 15 cm · 하천 500 m 이내 등 5 cm(2026판) | 자료 없음 | 센서 비공개. 적용 대상 후보만 «지침 적용 대상»에 표시 |
| 참고 | 하천 수위 · 강우 누적 · FloodOps 규칙(비교 후보) | 조건 아님 | 판단 근거로만 분리 표시 |

## 4. 원칙

- 공식 기준과 FloodOps 규칙을 섞지 않는다. FloodOps 규칙은 항상 «비교 후보»로 점선 표시한다.
- 자료가 없으면 무강우·정상으로 보이지 않게 «미확인 / 자료 없음»으로 드러낸다.
- 권고는 통제를 실행하지 않는다. «담당자 판단·현장 확인이 우선» 문구를 권고 옆에 둔다.
- 운영 등록 전 시설은 담당자 기록을 받지 않는다(등록 관문: 유입 경로·대표 관측소·현장 계측·검증 사건).
- 수치는 API 값을 그대로 쓰고 화면에서 다시 계산하지 않는다(채점표).

## 5. 발전 과제: 실제 지하차도 연결

흐름의 마지막 칸(공식 특보 → 시설 기준 적용 → 통제 검토·담당자 기록 → 사건 채점 → **실제 지하차도 연결**)은 지금 화면에 «발전 과제»로만 표시한다. 공개 API가 없어 기관 협력이 전제다.

| 연결 대상 | 화면에서 바뀌는 곳 |
| --- | --- |
| 진입차단시설 작동 기록 | 시설 판단 탭에 «권고 → 실제 차단» 시각 차이 표시 |
| 지하차도 침수심·배수펌프 계측 | 공식 기준 표의 «침수심» 행이 실제 판정으로 바뀜 |
| 지자체 통제·해제 기록 | 효과성 채점표의 정답이 보도 시각에서 공식 기록으로 바뀜 |
