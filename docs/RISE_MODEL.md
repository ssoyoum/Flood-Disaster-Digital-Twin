# 6시간 최대 수위 상승 예측 모델 (실명 관측소 재학습)

확인일: 2026-10-10. `water-level-rise` 연구(익명 관측소·합성 시각)의 입력 계약을 **홍수통제소 실명 관측소의 실제 시각 자료**에 그대로 적용해 다시 학습한 모델이다. `#twin` 보드의 "6시간 최대 상승 예측 · 연구 카드"가 이 모델을 쓴다. 통제 권고는 이 예측을 읽지 않는다.

## 무엇을 예측하나

- 목표: `max(WL(t+1h), …, WL(t+6h)) − WL(t)` (m). 앞으로 6시간 안의 최대 상승량이고 음수도 유효하다.
- 예측하지 않는 것: 도달 시각, 시각별 수위 곡선, 지하차도 침수심.
- 카드는 `WL(t) + 예측 상승량`을 관측소 공식 수위(주의보·경보·계획홍수위)와 비교해 "6시간 안 도달 예상"만 표시한다.

## 자료와 입력 계약

| 항목 | 값 |
| --- | --- |
| 수위 | 홍수통제소 홍수예보 지점 223곳 + 미호강 상·하류 = 224곳, 1시간 자료 2019-01-01~2026-10-10 (`docs/HRFCO_HISTORY.md`) |
| 강우 | 수위 관측소마다 가장 가까운 홍수통제소 강우 관측소(값이 없으면 2·3번째 후보), 188곳. 224곳 중 215곳 연결, 중앙값 거리 2.88 km |
| 입력 | 기준 시점·1·3·6·12·24시간 전 수위, 1·6·24시간 누적 강우, 파생 변화량·가속도·24시간 범위, 관측소별 중앙 수위·상승 표준편차·99% 분위 (연구 계약의 `FEATURES` + `make_features`) |
| 빠진 입력 | 연구 계약의 IMERG·레이더·유역 변수 16종은 이 경로에 없어 쓰지 않는다 |
| 행 선택 | 24시간 안에 수위가 0.2 m 이상 움직였거나, 목표가 ±0.2 m 이상이거나, 24시간 강우가 10 mm 이상인 "활동" 시간 전부 + 나머지 평온 시간의 5% 무작위 |
| 품질 | 1시간 사이 3 m 넘게 뛰는 값(미호강교 2023-05-16 같은 센서·기준면 오류)은 앞뒤 값까지 버린다. 지연·누락 시각은 빈 값으로 두고 정시 입력이 하나라도 없으면 행을 만들지 않는다 |
| 학습 | LightGBM 회귀(31 leaves, 800 라운드, 학습률 0.03). 관측소 통계는 학습 행에서만 계산 |
| 검증 | 연·월 단위 GroupKFold 4폴드(같은 달의 모든 관측소가 한 폴드) + **2023-07 한 달은 학습에서 완전히 제외**해 오송 사건 검증에 쓴다 |

```powershell
python data/scripts/train_rise_model.py              # 224곳, 교차검증 포함 약 10분
python data/scripts/train_rise_model.py --stations 3011665 3011635 3011685 --skip-cv
```

산출물: `data/models/rise_lgbm_1h.txt`(모델 텍스트, 2.4 MB), `rise_station_stats.json`, `rise_model_card.json`(아래 수치 전부), 같은 내용의 `data/manifests/rise-model.json`.

### 오송 2023-07-15 (미호강교 3011665, 학습에서 제외한 달)

| 임계 | 실제 도달(1시간 자료) | 모델 첫 «6시간 안 도달» | 단순 외삽 첫 예고 |
| --- | --- | --- | --- |
| 경보 8.0 m | 05:00 | 03:00 (**120분 전**) | 전날 16:00 (780분 전, 오경보) |
| 계획홍수위 9.38 m | 07:00 (10분 자료로는 06:50) | 04:00 (**180분 전**) | 03:00 (240분 전) |

사건 창(07-14 12:00~07-15 10:00) RMSE: 모델 1.01 m, 단순 외삽 1.58 m, 변화 없음 1.53 m. 모델은 01:00(수위 6.50 m, 6시간 강우 31 mm)부터 상승을 예측하기 시작해 04:00에 +1.98 m(실제 +2.51 m)를 냈다. 보드 재생 04:10에서는 수위 7.69 m + 1.94 m = 9.63 m → "계획홍수위 도달 예상"이 뜨고, 같은 시각 권고는 규칙대로 "감시"다. 규칙(`river_stage_v1`)의 첫 «통제 검토»는 05:50이므로, 예측 카드는 규칙보다 110분 앞서 같은 방향을 가리킨다.

주의: 03:00~04:00의 예측(+1.5~2.0 m)은 실제(+3.0 m)보다 작다. 전국 자료로 학습한 모델은 미호강교의 급상승을 보수적으로 본다. 미호강 3곳만으로 학습하면 같은 창에서 RMSE 1.01 m, 선행 180분으로 비슷했지만 홀드아웃 전체 성능은 떨어진다.

중요도(gain) 상위: `wl_change_6h`, `station_rise_std`, `wl_acceleration_3h`, `wl_change_1h`, `sfc_rain_1h`, `wl_above_station_median`.

## 보드와 API

- `GET /api/twin/facilities/{id}/rise-forecast?at=` — `backend/app/rise_model.py`. 시설 관측소의 26시간 창에서 정시 입력(`water_level_bridge.water_inputs`)과 강우 합계를 만들고 예측한다. 정시 입력이 하나라도 없거나(`MISSING_EXACT_LAGS`) 관측이 오래되면(`OBSERVATION_NOT_FRESH`) 예측하지 않는다. 모든 응답에 `kind: "RESEARCH"`, `control_decision_usable: false`.
- 실시간 모드의 강우: 기상청 어댑터가 없어 결측으로 들어간다(모델은 결측을 처리한다). 재생 모드는 2023년 청주금천 AWS 시간 강우를 쓴다. 학습 강우는 홍수통제소 강우계이므로 관측망이 다르다.
- 실행 환경: `lightgbm==4.7.0`, 컨테이너는 `libgomp1` 필요, 모델 파일은 `data/models/`로 이미지에 복사한다. 모델 파일이 없으면 카드가 "학습된 모델 파일이 서버에 없습니다"를 보여주고 다른 기능은 영향이 없다.

## 한계와 다음 단계

- 급상승 과소 예측: 1 m 초과 구간 RMSE 0.99 m. 분위 회귀(상한 예측)나 사건 가중 학습을 검토한다.
- 강우는 가장 가까운 지점 1곳의 합계다. 유역 평균 강우·레이더가 들어오면 연구 계약의 나머지 입력을 채울 수 있다.
- 학습에 없는 관측소는 관측소 통계가 결측으로 들어가므로 새 시설을 등록할 때는 그 관측소를 학습 목록에 넣고 다시 학습한다.
- 관측소 기준면이 서로 달라도 `wl_above_station_median`으로 보정하지만, 기준면 변경 이력이 있는 관측소는 따로 확인해야 한다.
