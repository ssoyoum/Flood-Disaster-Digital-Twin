# 인명피해우려지역 좌표 데이터 조사

- 조사일: 2026-10-19
- 목적: 인명피해우려지역을 시설 감시 목록과 구분하고, 공개 좌표를 `village` 대피 단위로 연결할 수 있는지 확인한다.

## 전국 데이터 경로

[행정안전부 재난안전데이터공유플랫폼의 «인명피해우려지역»](https://www.safetydata.go.kr/disaster-data/view?dataSn=749)은 공개 데이터 항목으로 등록되어 있다. 페이지는 목록 중 첫 100건만 샘플 다운로드로 제공하고, 전체 데이터 연계는 오픈 API를 이용하라고 안내한다. API 이용에는 공유플랫폼 회원가입과 별도 활용신청이 필요하다. 공개 설명에 나온 필드는 관리번호·지구명·지정 사유코드·지정일·해제일·상세 사유이며, 좌표 필드는 보이지 않는다.

따라서 국가 단위 9,412개소 전체를 현재 로컬에서 사용할 수 있다고 볼 근거는 없다. 이용 신청 후 실제 API 스키마에서 좌표 제공 여부를 확인해야 한다. 좌표가 없다면 관리기관에 위치자료를 별도로 요청한다.

## 좌표가 있는 지방자치단체 파일 사례

[공공데이터포털의 보령시 인명피해우려지역 파일](https://www.data.go.kr/data/15103988/fileData.do?recommendDataYn=Y)은 2026-08-22 기준 CSV 19행이며, 연간 갱신으로 표시된다. 파일은 로그인 없이 받을 수 있고 위도·경도 외에 피해예상지역 주소, 대피 기준·장소, 분류, 피해우려 유형도 포함한다.

공개 파일을 직접 내려받아 집계한 결과:

- 19/19행에 숫자로 읽히는 위도·경도 쌍이 있었다.
- 지번 주소는 17/19행, 도로명 주소는 10/19행에 있었다.
- 대피 기준은 13/19행, 대피 장소는 8/19행에 있었다.
- 19행은 침수 취약 시설, 자연재해위험개선지구, 급경사지, 태양광·해안·여가 시설 등 여러 종류가 섞여 있었다.

이 자료는 좌표가 공개되는 사례를 확인하는 데는 쓸 수 있지만, 보령시 19곳만 포함하고 대피 기준·장소가 일부 비어 있어 전국 마을 대피 기능의 데이터로 간주할 수 없다. 또한 모든 행이 마을을 뜻하지 않으므로 `village`로 일괄 분류하면 안 된다.

## FloodOps 연결 기준

- API 신청이 승인되기 전까지 전국 위험지역을 새 데이터 레이어나 위험 순위에 넣지 않는다.
- 좌표를 받은 뒤에도 지구 종류를 확인해 하천·침수 위험과 산사태·태양광·해안 위험을 나눈다. `village`는 실제 마을 대피 대상이 확인된 지구에만 쓴다.
- 공개 지점 좌표는 지구 경계나 대표 관측소 유입 경로를 증명하지 않는다. 관측소 근접만으로 운영 통제 규칙을 만들지 말고, 기준·대피 장소·갱신일을 원천 자료와 함께 보존한다.
- 보령 파일의 CSV 응답은 `charset=UTF-8`로 표기됐지만 CP949로 해석해야 한글 헤더가 복원됐다. 수집기 구현 시 파일 원본 인코딩을 확인해야 한다.
