# 멘토링 피드백과 대응 (2026-10)

발표 뒤 멘토링에서 받은 지적과, 그 뒤 조사·논의로 정한 대응을 정리한다. 멘토 지적은 팀이 전달받은 내용 그대로 적고, 조사 결과는 출처를 붙인다. 출처가 없는 판단은 «팀 판단»으로 표시한다.

## 1. 멘토 지적

| # | 지적 | 요지 |
| --- | --- | --- |
| M1 | 지침을 확인했나 | 지하차도 통제·경보에 이미 공식 기준이 있는데, 그걸 확인하고 설계했는지 |
| M2 | 데이터 중복 아닌가 | 공공데이터를 모아 다시 보여 주는 것과 무엇이 다른지 |
| M3 | 이미 있는 서비스 아닌가 | 홍수통제소 상황판, 행안부 체계, 경기연구원 홍수 예측 모델, NIA 홍수 알림–내비 연계(우수사례) |

| M7 | 사업화 | 누가 쓰고 어떻게 이어지는지 |

## 2. 조사로 확인한 것

### 2.1 기존 서비스와 겹치는가 (M3)

### 2.3 홍수통제소는 경보를 어떻게 정하나 (M1·M3) — 원문 확인

- **법적 근거**: 「수자원의 조사·계획 및 관리에 관한 법률」 제8조(홍수·갈수 예보의 실시). 하천법에는 예보 조문이 없다. https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=285271
- **절차**: 같은 법 시행규칙 제2조. 별표 1에 따라 발령하고, 발령·변경·해제 시 시·도지사, 시장·군수·구청장, 관계기관장에 지체 없이 통지한다. 시장·군수·구청장은 경찰·소방에 통지하고 주민에게 알린다. 홍수통제소장이 특보지점의 위치와 기준수위를 고시하고 10년마다 재검토한다. 2023-07 당시(환경부령 제764호)와 현행(기후에너지환경부령 제1호, 2025-10-01) 제2조 문구는 같다. https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=278947
- **발령 기준(별표 1)**: 주의보 기준수위는 계획홍수량 50% 유량의 수위, 또는 최근 5년 평균 저수위~계획홍수위의 60% 수위, 또는 주변 상황·제방을 고려해 정한다. 경보는 같은 방식으로 70%/80%. 기준수위에 가까워지거나 **초과가 예상될 때** 발령한다. 2024-05-10 개정으로 «급박하면 주의보 없이 바로 경보»의 유역면적 제한이 삭제됐다. https://www.law.go.kr/LSW/flDownload.do?flSeq=156767267&bylClsCd=110201
- **예측**: 10분 단위 수문자료로 유출량·댐 저수량을 계산해 수위를 판단하고, AI 모형이 10분마다 최대 6시간 앞을 예측하며 예보관이 비교해 발령한다. 예보지점 75곳 → 223곳(2024-05). https://www.hrfco.go.kr/web/floodPage/floodForecast.do · https://dshi.mods.go.kr/window/2024b/main/2024_win_06.html · https://www.korea.kr/news/policyNewsView.do?newsId=148929240
- **미호강교(3011665) 기준값**: 홍수통제소 API 값 관심 5.0·주의보 7.0·경보 8.0·계획홍수위 9.38 m, 기준면 19.643 m. 19.643 + 9.38 = 29.023 m로 국조실의 «계획홍수위 해발 29.02 m»와 맞아 **계획홍수위는 2023년에도 같았다고 간접 확인**. 주의보·경보 수위의 2023년 값은 고시 원문 미확인.
- 주무부처는 2025-10-01부터 **기후에너지환경부**다. 발표 자료의 «환경부» 표기를 맞춘다.

FloodOps에 주는 의미(팀 판단): 홍수특보는 **관측소** 단위에서 끝나고, 지하차도 같은 **시설**로 내려가는 판단은 2.2의 지침 (8)②에 따라 현장 몫이다. FloodOps가 다루는 구간이 이 «관측소 특보 → 시설 통제» 연결이며, 특보 자체를 다시 만들지 않는다.

## 3. 대응 방향 (팀 판단)

### 3.1 하지 않기로 한 것

- **더 정확한 예측 모델로 경쟁하지 않는다.** 홍수통제소·연구기관의 모델과 자료를 이길 근거가 없고, 오송에서 드러난 병목은 예측이 아니라 «특보가 시설 통제로 이어지지 않은 것»(공식 경보 → 유입 257분)이다.
- **자체 다요인 경보 기준을 만들어 기관에 쓰라고 하지 않는다.** 취약성 가중치·5단계 체계 설계는 보류한다(11/3 이후 필요하면 재개).

### 3.2 하기로 한 것

FloodOps의 자리를 **«공식 특보·기준을 시설 단위로 대입하고, 과거 사건으로 채점하는 마지막 구간»**으로 정한다.

| 지적 | 대응 |
| --- | --- |
| M1 지침 | 채점기의 입력을 FloodOps 규칙에서 **공식 기준**(홍수특보·하천 경보수위·계획홍수위·호우특보·행안부 침수심)으로 바꾼다. FloodOps 규칙은 «기준을 바꾸면 이렇게 된다»는 비교 후보로만 남긴다. 기준 원문 대장을 만든다 |
| M2 중복 | 공공데이터는 입력이고, 산출물은 «시설별 기준 적용 상태»와 «사건별 선행·지연·헛울림» 평가 결과다 |
| M3 기존 서비스 | 2.1 표로 «앞단(예측·특보)과 현장 통제 사이의 빈 층»을 보인다. 실제 지하차도 연결은 발전 과제(3.3) |
| M4 효과성 | 효과성 채점표를 화면·기획서에 같은 모양으로 넣는다. 늦은 사례(대전 2023)도 공개한다 |
| M5 특화성 | 기존 서비스는 «지금 어디가 위험한가», FloodOps는 «그 기준이면 그날 몇 분 있었나». 발표에서 전국 감시·에이전트·HAND를 앞에 두지 않는다 |
| M6 소관·대응 주체 | 사용자를 «통제 권한이 있는 지자체 도로·재난 부서»로 고정하고 시설마다 관리 주체를 표시한다. 알림 경로 공백(지자체 결정이 국민비서로 나가지 않음)은 문제 정의에 넣고, 출력 규격만 설계한다 |
| M7 사업화 | 다음 장마철 전 지자체 1곳에 기준 검증·사후검토 보고서를 무상 파일럿으로 제공 → 조달·용역 전환. 민간 데이터·보험은 «확보 계획»으로만 쓴다 |
| M8 실무자 검증 | 질문을 «우리 도구 평가»가 아니라 «결정 과정 기록»으로: 무슨 근거로 통제하나, 결정까지 몇 분, 헛울림 비용, 통제 기록은 어디에 남나. 2명 이상 기록. 같은 사건을 기존 방식과 FloodOps 화면으로 판단해 걸린 시간을 비교하는 탁상훈련 |

### 3.3 발전 과제: 실제 지하차도와 연결

지금 FloodOps는 «통제 검토 권고 → 담당자 기록»에서 끝난다. 다음 단계는 판단을 실제 지하차도 현장과 잇는 것이며, 공개 API가 없어 **기관 협력 과제**로만 둔다. 기능으로 약속하지 않는다.

- 진입차단시설: 통제 검토 권고와 실제 차단 작동 시각을 한 기록으로 묶어, 권고 → 실행까지 걸린 시간을 남긴다
- 현장 계측: 지하차도 침수심·배수펌프 가동 자료를 받아 행안부 침수심 기준 행을 «자료 없음»에서 실제 판정으로 바꾼다
- 통제 실행 기록: 지자체 통제·해제 기록을 받아 채점표의 정답(지금은 보도 시각)을 공식 기록으로 바꾼다
- 전제: 시설 관리 주체(지자체 도로·재난 부서)와의 협약, 자료 제공 방식 합의

### 3.4 민관협력 구조 (M6·M7)

FloodOps 팀이 «민»이다. 관은 데이터·기준·권한을 갖고, 민은 그걸 시설 단위 판단 도구와 검증 보고서로 바꾼다. 통제 결정은 대신하지 않는다.

| 관 (기관이 주는 것) | 민 (FloodOps 팀이 하는 것) |
| --- | --- |
| 홍수특보·수위(홍수통제소), 호우특보(기상청) | 특보를 시설 단위로 내려 지침 2.1.7(8) 즉시 통제 조건 충족 여부와 기준까지 남은 시간 판정 |
| 통제 지침(국토부), 시설 목록·관리 주체 | 시설 등록·관문 관리(대표 관측소·유입 경로·지침 적용 대상) |
| 통제 권한과 결정(지자체 도로·재난 부서) | 판단 화면과 담당자(상·하행) 확인 기록 |
| 실제 통제·해제 기록 | 과거 사건 채점, 사후검토·기준 개정 근거 보고서 |

함께 들어올 민간 협력처(모두 **협력 제안·확보 계획**이며 기능으로 약속하지 않는다):

| 민간 협력처 | 협력 내용 | 상태 |
| --- | --- | --- |
| 민간 클라우드(NHN Cloud, 민관협력 지원 플랫폼 제공) | 운영 서버. 수상 시 2027-12까지 연장 | 계정 발급(2026-10-19), 배포 전 |
| 진입차단시설·수위센서 제조·설치 업체 | 3.3 «실제 지하차도 연결»의 상대. 차단 작동 기록·침수심 값 연동 규격 → 침수심·①⑤ 조건 판정, 조건 충족 → 실제 차단까지 걸린 시간 | 공개 API 없음, 협약 필요 |
| 지자체 상황관리 시스템 구축 업체(SI) | 지자체 상황실 화면에 시설 판정 결과 연계 | 후보 |
| 보험사(침수 청구 이력) | 실제 침수 위치로 검증 정답 보강 | 계획 |

첫 단계(팀 판단): 이미 채점한 사건이 있는 지자체 1곳(충북 또는 대전)과 그 지자체 차단시설 업체 1곳으로 다음 장마철 전 파일럿 → 기준 검증·사후검토 보고서 무상 제공 → 조달·용역 전환. 민간 클라우드는 공모전 전에 NHN Cloud 배포를 실제로 해 «민간 자원 활용»을 기능으로 증빙한다.
