# 홍수통제소 OpenAPI로 전국 관측 이력 확보

확인일: 2026-10-10. 대회 자료(`water-level-rise`, 익명 관측소·합성 시각)를 쓰지 않고, 같은 종류의 관측을 **원출처인 홍수통제소 OpenAPI**에서 실명 관측소·실제 시각으로 받는 방법과 확인 결과다.

## 전국에서 받을 수 있는 것 (키 하나, 무료)

`api.hrfco.go.kr/{키}/…` 한 키로 아래 전부를 조회했다. 목록은 `data/manifests/hrfco-stations.json`에 있다.

| 종류 | 관측소 수 | 기관 | 비고 |
| --- | ---: | --- | --- |
| 수위 `waterlevel` | 1,420 | 기후에너지환경부 1,025 · 수자원공사 250 · 농어촌공사 88 · 수력원자력 27 등 | 좌표 1,408곳, 계획홍수위(`pfh`) 977곳, 홍수예보 지점 223곳. 관심·주의보·경보·심각 수위 포함 |
| 강우 `rainfall` | 744 | 기후에너지환경부 466 · 수자원공사 205 · 수력원자력 35 등 | 좌표 742곳. 기상청 키 없이 강우를 받을 수 있는 경로 |
| 댐 `dam` | 58 | 수자원공사 42 · 수력원자력 8 · 농어촌공사 6 | 방류·저수위 |
| 보 `bo` | 17 | 수자원공사 | 계획홍수위·관리수위 |

시계열 조회 한도(2026-10-10 실측, 미호강교 3011665):

| 간격 | 한 번에 받은 범위 | 행 수 | 소요 |
| --- | --- | ---: | ---: |
| `1H` | 1년(2023-01-01~12-31) | 8,760 | 1.1초 |
| `10M` | 15일 | 2,160 | 2.3초 |
| `1D` | 약 1년(요청 범위가 길면 최근 1년만) | 366 | 0.2초 |

즉 관측소 하나의 8년 시간 자료는 8번, 홍수기(6~9월) 10분 자료는 해마다 9번 호출로 끝난다. 전국 1,420곳 × 8년 시간 자료도 약 11,000회 호출이면 되고, 호출당 0.35초 간격을 두면 하루 안에 받을 수 있다.

주의: 비홍수기에는 10분 값이 수십 분 늦게 채워지거나 비어 있을 수 있다(미호강교 2026-10-10 확인). 실시간 보드는 10분 값이 비면 1시간 값으로 대체한다(`backend/app/twin.py`).

## 스크립트

```powershell
python data/scripts/collect_hrfco_history.py catalog                         # 전국 목록 → data/manifests/hrfco-stations.json
python data/scripts/collect_hrfco_history.py nearest --kind rainfall --lon 127.3376 --lat 36.6246 --limit 5
python data/scripts/collect_hrfco_history.py fetch --kind waterlevel --stations 3011665 3011635 3011685 --interval 1H --years 2019-2026
python data/scripts/collect_hrfco_history.py fetch --kind rainfall --stations 30114070 30114110 30114020 --interval 10M --years 2019-2026 --months 6-9
```

- 원본 응답 JSON은 `data/raw/hrfco/{kind}/{code}/`(git 제외)에 그대로 두고, 관측소별 병합 CSV는 `data/processed/hrfco/{kind}_{code}_{interval}.csv`에 만든다. 10분 CSV는 커서 git에서 제외하고 원본 JSON과 manifest로 다시 만든다.
- 모든 수집은 `data/manifests/hrfco-history.json`에 관측소·간격·기간·행 수·유효 수·연도별 분포·SHA-256으로 기록된다.
- 키는 `.env`의 `HRFCO_API_KEY`에서 읽고 파일에 쓰지 않는다. 같은 요청은 원본 JSON이 있으면 다시 부르지 않는다.

## 다른 제공처와의 관계

- 기상청 API허브(AWS 분 자료·특보)는 별도 키와 API별 활용신청이 필요하다. 강우 관측망은 홍수통제소 744곳과 기상청 AWS가 다르므로, 두 출처를 같은 시설에 붙일 때는 관측소 거리와 집계 간격을 따로 기록한다.
- WAMIS(국가수자원관리종합정보)도 같은 관측소의 일·시 자료를 제공하지만, 실시간과 10분 자료는 홍수통제소 OpenAPI가 유일하다.
- 대회 자료의 레이더 강우·IMERG·유역 변수는 이 경로에 없다. 유역 상수(집수면적·경사·토지피복)는 WAMIS 유역도와 Copernicus DEM으로 만들 수 있고, 레이더는 기상청 API허브에서 받는다.
