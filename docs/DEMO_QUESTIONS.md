## 시연할 때 주의

- **응답 시간은 6~18초다.** 질문을 보낸 뒤 "도구를 고르는 중" 상태 문구를 가리키며 설명을 이어간다.
- **실시간(F1)은 평상시 "정상"으로 나온다.** 극적인 장면은 재생 시각 06:00(F2)으로 보여준다.
- **F5의 "70분 먼저"는 현재 규칙(05:50)과 비교한 값이다.** 유입 기준으로는 157분 → 227분이다.
- **Gemini 일일 할당량이 끝나면 HTTP 429가 난다.** 시연 당일 아침에는 질문을 많이 돌리지 않는다. 모델이 없으면 규칙 플래너(결정론)로 답이 나오지만 문장이 딱딱하다.
- **공개 서버(10-01 빌드)에는 통제 판단 보드와 시설 판단 질문(F1~F5)이 없다.** 공개 URL로 시연하려면 재배포가 먼저다.
- **수치의 한계를 말로 덧붙인다.** 157분·70분은 2026년에 다시 받은 보관 수위와 현재 기준값으로 계산했다. "그날 실제로 157분을 확보했을 것"이라는 주장이 아니다(에이전트도 답에 같은 단서를 붙인다).
